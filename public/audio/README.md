# Demo tracks

Drop royalty-free files here to replace the procedural placeholder loops:

- `demo-1.mp3`: "Pulse Engine" preset
- `demo-2.mp3`: "Night Drift" preset
- `demo-3.mp3`: "Glass Shatter" preset
- `demo-4.mp3`: "Still Water" preset

Titles and paths live in `src/audio/demoTracks.ts`. If a file is missing, the app
falls back to a synthesized loop rendered in the browser, so the demo never breaks.
